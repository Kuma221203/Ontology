# Tuần 3 — Tổng Quan & Mục Lục

> Chuyển từ Protégé (GUI, thao tác tay) sang code — nền tảng bắt buộc để sau này tự động hóa populate dữ liệu thật từ ERP/MES.

## Mục tiêu tuần này

Biết thao tác RDF/OWL hoàn toàn bằng Python: đọc/ghi triple (`rdflib`), chạy reasoner từ code (`owlready2`), truy vấn bằng SPARQL — đủ để tự động populate hàng trăm nghìn instance thay vì gõ tay trong Protégé.
